## 1. 토큰 (색·글자·간격 값)

**원본은 `design/tokens.json` 하나뿐이다.** 값을 바꿀 때는 이 파일만 고치고 CSS를 다시 만든다.

```bash
node design/scripts/make-tokens-css.js design/tokens.json design/tokens.css
```

```bash
node design/scripts/contrast.js design/tokens.json
```

- `make-tokens-css.js`: tokens.json을 앱에서 쓸 `tokens.css`로 바꾼다. Phase 3에서 이 파일을 `src/styles/`로 복사해 쓴다.
- `contrast.js`: 글자색과 바탕색 조합이 충분히 잘 읽히는지(명도 대비 4.5:1 이상) 검사한다. 색을 바꾸면 꼭 돌린다.
- 같은 tokens.json을 디자인 시스템과 캔버스(`project/ds/tutor/`)에도 넣었다. 색을 바꾸면 세 곳을 모두 갱신해야 한다.

### 1.3 글자 스타일

캔버스에서는 클래스 이름이 `.display`처럼 짧고, 앱 tokens.css에서는 `.type-display`이다. 값은 같다.
CSS Modules에서는 `composes` 대신 `var(--type-display-size)` 같은 변수를 직접 쓴다.

| 스타일 | 크기 / 줄높이 / 굵기 | 쓰는 곳 |
|---|---|---|
| `display` | 34 / 40 / 700 | 화면 제목 (오늘의 연습, 보관함) |
| `sentence` | 28 / 36 / 600 | 쉐도잉·복습 문장, 퀴즈 문제 |
| `numeral` | 48 / 48 / 700 | 큰 숫자 (복습할 문장 8) |
| `title` | 22 / 28 / 700 | 카드 제목, 레벨 |
| `headline` | 17 / 24 / 600 | 버튼 글자, 목록 첫 줄 |
| `body` | 17 / 26 / 400 | 영어 본문, 설정 항목 이름 |
| `body-kr` | 16 / 26 / 400 | 한국어 설명. `word-break: keep-all` 필수 |
| `caption` | 13 / 18 / 500 | 번역, 보조 설명, 진행 수치 |
| `tab` | 11 / 13 / 600 | 탭바 글자 |
| `label` | 12 / 16 / 600, 고정폭 글꼴, 자간 0.08em | 작은 머리말 (오늘 복습, LESSON 03) |

- 글꼴은 기기 기본 글꼴을 쓴다(SF Pro + Apple SD Gothic Neo). 웹 글꼴을 내려받지 않는다.
- 숫자가 바뀌는 곳에는 `font-variant-numeric: tabular-nums`를 붙여 숫자 폭을 고정한다. 그래야 숫자가 바뀔 때 글자가 흔들리지 않는다.
- 한국어 문장에는 `word-break: keep-all`을 붙인다. 붙이지 않으면 단어 중간에서 줄이 바뀐다.

## 2. 디자인 시스템 부품 9개와 상태

| 부품 | 상태 / 변형 | 메모 |
|---|---|---|
| **Button** | primary · secondary · ghost / 기본 · 눌림(`:active`) · 꺼짐(`disabled`) · 초점 / 크기 기본(52px), sm(44px) / block(가로 꽉) | 위험 동작은 ghost + 글자색 `--danger` |

| **WordHighlight** | 기본 · 다음 단어(`--next`, 밑줄) · 맞힘(`--matched`, 파란 칩) · 틀림(`--wrong`, 주황 물결 밑줄) | 단어는 인식되는 대로 왼쪽부터 채운다 |

### 4.1 그리지 않았지만 만들 때 정할 것

- **더보기 화면**: 따로 그리지 않았다. 롤플레잉 · 프롬프트 만들기 · 진도 · 설정 4줄을 SettingsRow의 화살표 줄로 나열한 단순한 목록으로 만든다.
- **단어 퀴즈 모드 1(카드)**: 큰 카드 한 장에 단어(`sentence`)가 있고, 탭하면 뒤집혀 뜻·품사·출처 문장이 보인다. 아래에 "몰랐어요 / 알았어요" 버튼 2개를 두고, 누른 결과로 SRS 간격을 정한다.
- **단어 퀴즈 모드 3(빈칸)**: 06 복습 화면과 같은 배치다. 출처 문장에서 그 단어만 HintBlank로 가리고, 마이크로 뜻이나 문장 전체를 말해서 푼다.
- **Gemini로 만든 롤플레잉 대사**: 음성 파일이 없으므로 튜터 말풍선에서 듣기 버튼을 뺀다. 라벨 옆에 "글자만" 표시를 붙인다.
- **빈 상태**: 보관함이나 단어장이 비었을 때는 `body-kr` 한 줄 안내와 secondary 버튼 하나("코스 둘러보기")를 둔다.

## 5. 반응형 기준 (화면 폭에 따라 바뀌는 규칙)

| 폭 | 배치 |
|---|---|
| 768px 미만 (iPhone) | 한 칸. 화면 좌우 여백 `--space-4`. 탭 화면은 아래 탭바, 연습 화면(수업·쉐도잉·변형·복습·퀴즈·롤플레잉)은 탭바 없이 왼쪽 위 닫기(X) |
| 768px 이상 (iPad, **가로·세로 모두**) | 두 칸. 왼쪽 `--column-list`(360px) + 오른쪽 나머지. 오른쪽 내용은 최대 폭 720px(쉐도잉 무대는 640px) |

- iPad 캔버스는 **가로 1180×820(iPad Air 11")을 가정하고** 그렸다. 세로(820×1180)에서도 같은 두 칸이고, 오른쪽 칸이 좁아질 뿐이다.
- iPad 탭바는 화면 아래 가운데에 탭 5개를 120px씩 둔다. 연습 화면에는 iPhone처럼 탭바가 없다.
- 미디어 쿼리 안에서는 CSS 변수를 쓸 수 없어서 `@media (min-width: 768px)`에 숫자를 직접 쓴다. 값은 `--bp-ipad`와 같다.
- **위아래 여백은 고정값이 아니다.** 캔버스의 위 59px·아래 34px(iPhone), 위 24px·아래 20px(iPad)은 노치와 홈 막대 자리를 흉내 낸 것이다. 앱에서는 `env(safe-area-inset-top)` 같은 값으로 기기가 알려 주는 만큼 비운다. 이렇게 하려면 `viewport-fit=cover` 메타태그가 필요하다.
- **탭바는 앱에서 화면 아래에 고정된다.** 캔버스에서 이름에 "스크롤 전체"가 붙은 화면(11·12·13)은 스크롤 길이 전체를 펼쳐 그린 것이라 탭바가 맨 아래에 있다. 실제로는 내용만 스크롤된다.

## 6. 접근성 · 공통 규칙

- 누르는 것은 모두 44×44px 이상이다(`--tap-min`).
- 아이콘만 있는 버튼에는 `aria-label`을 붙인다(닫기, 듣기, 저장, − / +).
- 아이콘은 직접 그린 선 SVG(굵기 1.75, 모서리 각짐)를 쓴다. 이모지는 쓰지 않는다. 앱에서는 `src/components/icons/`에 모은다.
- 움직임은 짧게 한다(색 바뀜 120~150ms). 기기에서 동작 줄이기를 켜면 마이크 고리 애니메이션을 멈춘다.
- 색을 바꾸면 반드시 `contrast.js`로 다시 검사한다.
